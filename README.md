# docshift

Převodník kancelářských dokumentů (DOCX, PPTX, XLSX, ODT, ODP…) do PDF a Markdownu. Příkazová řádka: vstupní soubor → výstupní složka. Obrázky se uloží jako číslované soubory a Markdown na ně odkazuje.

Určeno pro vývojáře, kteří potřebují dostat kancelářský dokument do podoby, kterou přečte LLM (DigiLearn, TalkSlides). Není to produkt pro koncové uživatele.

**Spec.** Kód zatím neexistuje. Viz [research](docs/research/), [GLOSSARY.md](GLOSSARY.md) a spec v issues.
